## 重新部署 agent-layout（遇到沙箱构建崩溃并解决）
- 同样 `npm run build && npm run preview -- --host 0.0.0.0 --port 3000` 今天连续两次失败：沙箱里 `vite build` 退出时触发 Node `ResetStdio()` assertion（`src/node.cc:760`），3000 端口未监听，60s 超时。本地构建正常，确认是沙箱环境问题而非代码。
- 改用 dev server（`npm run dev -- --host 0.0.0.0 --port 3000`）也失败（URL 不可达）。
- 最终解法：把 build 输出重定向 + 用 `;` 而非 `&&` 分隔：
  `npm run build >/dev/null 2>&1; npm run preview -- --host 0.0.0.0 --port 3000`
  一次成功。原因：静默重定向避免写 stdout 管道，绕开 ResetStdio 崩溃；`;` 保证即使 build 退出码异常也继续 preview。

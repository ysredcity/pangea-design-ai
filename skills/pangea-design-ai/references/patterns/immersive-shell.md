# 沉浸式 Agent 布局外壳

对应设计规则 [design.md 2.1](../design.md#21-界面形态选型)。**中间优先、两侧辅助**：左侧帮助用户找到任务，中间推进任务，右侧处理任务对象。

## 页面结构

```
┌───────────┬─────────────────────────┬───────────────┐
│           │                         │               │
│  左侧菜单栏  │        中间对话流          │   右侧独立面板    │
│  （非必需）  │                         │  （按需打开/关闭） │
│           │  ┌───────────────────┐  │               │
│ 入口/任务    │  │  消息气泡（用户/AI） │  │  文档/表格/代码/  │
│ 项目/历史    │  │  澄清卡片/确认卡片    │  │  图表/详情/预览/  │
│ 会话/智能体  │  │  制品卡片（摘要）    │  │  配置/引用资料    │
│ 切换/全局导航│  └───────────────────┘  │               │
│           │  ┌───────────────────┐  │               │
│           │  │   意图输入区（Composer）│  │               │
│           │  └───────────────────┘  │               │
└───────────┴─────────────────────────┴───────────────┘
    240px           ≥440px                  ≥320px
```

## 区块职责

| 区域 | 核心职责 | 是否必需 |
|---|---|---|
| 左侧对话管理菜单栏 | 管理入口、任务、项目、历史会话、智能体切换与全局导航 | 否——单一场景/单一智能体产品可省略 |
| 中间对话流 | 承载用户意图、智能体响应、任务过程、工具调用、确认和反馈 | 是——**主区域，不可被压缩至不可读** |
| 右侧独立面板 | 展示文档、表格、代码、图表、详情、预览、配置、引用资料等任务对象 | 按需——由[制品卡片](../design.md#35-结果呈现)点击驱动打开，非常驻 |

## 独立性 / 专注性 / 连贯性

- **独立性**：界面脱离主应用运行，不依赖外部窗口或组件。
- **专注性**：隐藏系统级通知、任务栏及无关控件，可视区域内仅保留与当前任务相关的功能入口。
- **连贯性**：支持同一语境下的连续追问。

## 响应式降级

遵循 [design.md 2.2](../design.md#22-响应式降级跨界面形态) 的通用规则，沉浸式的具体行为：

- **第一降级点**（视口 < 三区最小宽度之和）：左侧菜单栏收起为抽屉。
- **第二降级点**（视口 < 对话流+面板最小宽度之和）：右侧面板升级为**覆盖式抽屉或对话框**——可关闭回到对话流，也可通过对话流中的制品卡片再次打开。
- 移动端（<768px）：单栏任务流，输入框/停止生成/返回/关闭面板等关键操作稳定可达。

## 与脚手架的对应

`templates/immersive-starter/src/components/layout/ImmersiveShell.tsx` 提供三栏容器组件，接受 `sidebar`（可选）、`children`（对话流内容）、`panel`（右侧面板内容，受控开关）三个插槽。新页面/新场景不修改该组件本身，只在插槽内组装 `agent-ui/` 中的对话组件。

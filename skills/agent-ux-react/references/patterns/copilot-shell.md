# 助手式 Copilot 布局外壳

对应设计规则 [design.md 2.1](../design.md#21-界面形态选型) 与 [2.3](../design.md#23-助手式布局子类型选择)。AI 是辅助角色，**不能抢占主工作区**。

## 页面结构（三栏并列，默认形态）

```
┌───────────┬─────────────────────────┬───────────────┐
│           │                         │               │
│ 左侧资源/  │      中间主工作区          │  右侧对话辅助区   │
│  项目区    │                         │               │
│           │  画布/代码编辑器/表格/     │  意图输入/任务解释/│
│ 文件/图层/  │  设计稿/数据看板/         │  工具调用过程/    │
│ 数据源/页面/│  业务详情页               │  建议方案/局部确认/│
│ 任务树/    │                         │  与当前对象相关的  │
│ 项目目录/   │                         │  AI 操作         │
│ 历史版本/   │                         │               │
│ 业务对象列表 │                         │               │
└───────────┴─────────────────────────┴───────────────┘
    240px          ≥320px（主工作区）        ≥440px
```

## 区块职责

| 区域 | 核心职责 |
|---|---|
| 左侧资源/项目区 | 管理文件、图层、数据源、页面、任务树、项目目录、历史版本或业务对象列表 |
| 中间主工作区 | 承载用户主要操作对象，例如画布、代码编辑器、表格、设计稿、数据看板、业务详情页 |
| 右侧对话辅助区 | 承载意图输入、任务解释、工具调用过程、建议方案、局部确认和与当前对象相关的 AI 操作 |

> 注意最小宽度分配与沉浸式相反：**主工作区的宽度优先级高于对话区**（对话区最小宽度 440px 是"退让"的一方，见响应式降级）。

## 三种子类型（不做三栏并列时）

| 子类型 | 特征 | 适用 | 不适用 |
|---|---|---|---|
| **浮窗** | 可拖拽到任意位置、可缩放，遮挡原页面内容 | 无需与主页面对照操作 | 需要对照操作的场景 |
| **浮层抽屉** | 压缩原页面空间，占据中右/左一部分，与主页面共用顶部导航，内容无遮挡 | 需与主页面信息对照、或频繁交互 | -- |
| **侧边抽屉** | 压缩原页面空间，与主页面左右布局 | -- | 主页面信息密度大、横向空间紧张 |

**选型建议**：默认优先三栏并列（信息密度可控、不遮挡）；宿主是已有产品的局部增强场景（如在现有工具里"加一个 AI 面板"）更适合浮层抽屉；纯粹的轻量辅助、不需要长期占用布局空间时用浮窗。

## 响应式降级

遵循 [design.md 2.2](../design.md#22-响应式降级跨界面形态)，助手式的具体行为：

- **优先保障主工作区**（对话流可以先退让）——与沉浸式"优先保对话流"相反。
- **第一降级点**：左侧资源/项目区收起为抽屉。
- **第二降级点**：右侧对话辅助区收起为抽屉（触发按钮展开），主工作区占满剩余空间；移动端进一步**升级为全屏模式**，但需保留触发对话流打开的按钮。

## 与脚手架的对应

`templates/copilot-starter/src/components/layout/CopilotShell.tsx` 提供三栏容器组件，接受 `resourcePanel`（左，可选）、`children`（中间主工作区内容）、`assistant`（右侧对话辅助区，受控开关/浮层模式）三个插槽。切换浮窗/浮层抽屉/侧边抽屉子类型通过 `assistantMode` prop 控制，不需要重写外壳组件。
